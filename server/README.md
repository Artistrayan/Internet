# Internet measurement node

This service provides real HTTP measurements against the deployed node. It does not report estimated device bandwidth or fabricate network telemetry.

## Endpoints

- `GET /healthz`: process health only; not a network-quality metric.
- `GET /v1/probe`: uncached HTTP probe. The client measures round-trip time with its monotonic clock.
- `GET /v1/download?bytes=N`: streams exactly N cryptographically generated bytes. The client measures bytes actually received and elapsed time.
- `POST /v1/upload`: accepts an octet-stream test payload and confirms the exact byte count received.

The generated download/upload payload is benchmark traffic, not synthetic telemetry. Throughput is calculated only from bytes transferred over the real connection and measured elapsed time.

## Configuration

- `PORT`: listener port (default 8080).
- `HOST`: bind address (default 0.0.0.0).
- `ALLOWED_ORIGINS`: comma-separated exact browser origins permitted by CORS. Configure the deployed frontend origin; do not use a wildcard in production.
- `TRUST_PROXY=true`: enable only when deployed behind a trusted reverse proxy.

## Run

```sh
npm install
npm run server
```

The web client requires `VITE_MEASUREMENT_API_URL` to point to this service. Until a real measurement node is deployed and configured, the UI must show that measurements are unavailable rather than display placeholder metrics.

## Limits

This is a single-node measurement service, not yet a global accelerator or traffic relay. It does not alter the ISP path, provide extra last-mile capacity, or claim to optimize unrelated application traffic. Global routing, multi-path bonding, device-level packet control, and router agents require separate implementations and deployment.
